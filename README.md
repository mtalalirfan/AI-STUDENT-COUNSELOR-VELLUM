# AI-STUDENT-COUNSELOR
AI-powered student advisor for career, education, scholarships &amp; international study planning, built with Gemini, Python, Streamlit, React, Material UI &amp; FastAPI.
It is an AI-powered student education, career, scholarship, and international study advisor built with Gemini, Python, Streamlit, React, Material UI, and FastAPI. It analyzes a student's academic profile, capabilities, learning behavior, career goals, finances, country preferences, scholarships, university strategy, immigration considerations, and long-term plans to generate evidence-grounded, brutally realistic recommendations.
Built for Students with hassle free answers to most important questions students miss out!
